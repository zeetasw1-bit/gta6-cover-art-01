Vice Cover Studio — a GTA 6-style cover art maker. Load your photos, arrange
them in multi-panel poster layouts, add a bold caption, grade it sunset or
neon, and export a share-ready PNG (1080x1080, 1080x1350, 1920x1080). Runs
fully offline in a desktop browser; photos never leave your machine.

## Run it

```sh
node serve.ts
# open http://localhost:8080
```

## How it works

1. **Add photos** — pick images from your machine (or try a sample).
   Click a thumbnail to place it on the selected panel.
2. **Arrange** — choose a layout (Vice Grid, Sunset Strip, or Hero), drag
   inside a panel to pan its photo, and zoom with the slider. One photo can
   fill every panel, or each panel can hold a different one.
3. **Caption & grade** — write a main caption and sub-caption, pick the
   Sunset, Neon, or Noir grade, and toggle vignette, grain, or neon glow.
4. **Export PNG** — one click downloads `cover-<WxH>.png` at the size you
   picked.

The caption is set in Anton (SIL Open Font License, bundled under
`app/fonts/` with its license text). All artwork in the sample photos is
original; nothing here uses Rockstar Games logos, artwork, characters, or
fonts.
